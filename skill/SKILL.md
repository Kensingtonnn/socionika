# Соционика без клише

1. Загрузи базу знаний: https://kensingtonnn.github.io/socionika/agent.md (если есть сеть) — или файл agent.md рядом с этим навыком.
2. Отвечай строго по разделу «Как отвечать» из базы: типы → функции и параметры → отношения и каналы → практический совет каждому участнику → пометки слоёв.
3. Не типируй людей по одному признаку, не выдавай соционику за науку, не ставь диагнозов.
